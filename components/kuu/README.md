# components/kuu

「くぅ」の表示ロジックをここに閉じ込める。呼び出し側は `import { Kuu } from "@/components/kuu"` のみを使い、
内部実装(画像アセット)を意識しない。

将来さらに差し替える際は、`Kuu.tsx` の内部実装のみを変更し、呼び出し側のコードは変更しない(MVP仕様書§12.1・§14)。

## ビジュアルアセットの出所(2026-07-17差し替え)

`public/kuu/*.png` は、創業者がAI画像生成ツールに自身でプロンプトして作成した5表情パターン
(ニュートラル/そっと寄り添う/受け止める/力を抜かせる/そっと背中を押す)から切り出したもの。

- MVP仕様書§12.1では当初「シンプルなSVG図形・外部発注/AI生成なし」と決定していたが、
  2026-07-17に創業者の判断でこのAI生成イラストへの差し替えを決定
- 使用したAI画像生成ツールの商用利用規約は**未確認**。一般公開前に利用規約を確認し、
  問題があれば差し替えること(§16.5の音源権利管理と同様の考え方)
- 現在使用しているのは `neutral`(ホーム画面)のみ。他4表情は将来のくぅ発話カタログ
  (設計書§15.2・`lib/kuu-lines.ts`は未実装)と連動させる想定の未使用アセット
